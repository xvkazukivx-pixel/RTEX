Vite Dev Server

⚡ RTEX Frontend & Backend

Vite Frontend Development Server aktif pada port 5173. Seluruh rute aplikasi RTEX dan API di-proxy secara mulus ke Laravel Backend pada port 8000.

🔐 Buka Halaman Login RTEX → 🌐 Akses Backend Langsung (Port 8000) ↗
$ cd frontend && npm run dev
$ cd backend && php artisan serve
